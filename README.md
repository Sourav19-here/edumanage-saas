# EduManage SaaS MVP

Dependency-free coaching center management MVP built from the business plan.

## Open locally

Open `index.html` in a browser. The app uses `localStorage`, so demo edits stay on the same browser until you reset the demo data.

## Included workflows

- Owner dashboard with attendance, fees, collection health, and follow-ups
- Student enrollment and profile editing
- Mobile-friendly attendance marking by batch and date
- Fee collection, overdue tracking, and payment history
- WhatsApp-style reminder queue with copy and sent states
- Printable PDF-style receipts
- Institute settings, plan selector, language toggle, JSON export

## Files

- `index.html` - app shell and navigation
- `styles.css` - responsive SaaS UI
- `app.js` - data model, local persistence, and core workflows
